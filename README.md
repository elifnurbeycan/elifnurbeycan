## Java & Spring Boot Projects

### [Visitor & Meeting Room Management System](https://github.com/elifnurbeycan/visitor-meeting-management)

A multi-tenant SaaS backend developed with **Java 21 and Spring Boot** for company-wide meeting room reservations.

- Designed REST APIs for companies, users, rooms, reservations, notifications, audit logs, and reporting.
- Implemented JWT authentication and granular authorization with Spring Security.
- Used PostgreSQL, Spring Data JPA, Redis, Flyway, MapStruct, and Apache POI.
- Added tenant isolation, reservation conflict checks, rate limiting, audit logging, and automated tests.

### [ATS — Applicant Tracking System](https://github.com/elifnurbeycan/ats-system)

A multi-tenant applicant tracking backend for managing candidates, positions, interviews, and recruitment workflows.

- Built with Java 21, Spring Boot, Spring Security, and PostgreSQL.
- Integrated Keycloak using OAuth 2.0, OpenID Connect, and JWT authentication.
- Implemented company and department-based data isolation with role and permission-based authorization.
- Used Flyway, Hibernate, MapStruct, JUnit 5, MockMvc, and Docker-based development services.

### [Announcement Tracker](https://github.com/elifnurbeycan/announcement-tracker)

A Spring Boot application that monitors official announcement sources and sends relevant updates to employees.

- Developed independent web-scraping strategies with Jsoup and scheduled parallel source scanning.
- Implemented Keycloak-based identity management and role-based access control.
- Used PostgreSQL, Spring Data JPA, Liquibase, email outbox processing, and retry handling.
- Added integration and end-to-end tests with Testcontainers and Playwright.

## Other Featured Projects

### [SafeWorker](https://github.com/elifnurbeycan/SafeWorker)

A full-stack worker-safety MVP that uses mobile devices as IoT endpoints for real-time risk detection and monitoring.

- Built a complete system with a **Node.js/Express backend**, **React dashboard**, and **Flutter mobile application**.
- Collected and processed mobile sensor signals such as accelerometer, gyroscope, GPS, battery level, and network status.
- Implemented risk scoring, SOS alerts, and QR-based danger-zone workflows.
- Added real-time Socket.IO notifications and CSV reporting.
- Combined backend logic, live data processing, dashboard UX, and mobile interaction in a practical safety product.

### [Galactic Shooter 2D](https://github.com/elifnurbeycan/Galactic-Shooter-2D)

An arcade-style space shooter focused on responsive gameplay, scoring, enemy behavior, and player feedback.

- Developed gameplay logic for player movement, shooting, enemy behavior, collisions, and scoring.
- Worked on the core game loop, including challenge, pacing, feedback, and replay motivation.
- Explored how game feel, visual feedback, and difficulty influence player engagement.
- Strengthened my Unity and interactive game-development skills.

### [Gladiator Duel — Reinforcement Learning Game AI](https://github.com/elifnurbeycan/GladiatorDuel_AI)

A turn-based Unity game featuring an adaptive AI agent developed with Q-Learning.

- Designed turn-based combat mechanics around strategy and player actions.
- Implemented a Q-Learning agent capable of improving its behavior through interaction with the game environment.
- Applied reinforcement learning concepts such as states, actions, rewards, and exploration.
- Combined my interests in game development, artificial intelligence, and experimentation.

### [Credit Card Default Prediction](https://github.com/elifnurbeycan/credit-card-default-prediction)

A machine learning project covering exploratory data analysis, preprocessing, feature engineering, Random Forest modeling, hyperparameter optimization, and evaluation.

- Used the UCI credit card default dataset to predict customer default risk.
- Performed exploratory data analysis, data preprocessing, and feature engineering.
- Created features such as average payment delay, total bill, total payment, and payment ratio.
- Trained and optimized a Random Forest classification model.
- Evaluated model performance using accuracy, ROC-AUC, precision, recall, and F1-score.

### [NetProbe — Reliable File Transfer over UDP](https://github.com/elifnurbeycan/NetProbe-UDP-Reliable-File-Transfer)

A networking project exploring reliable file transfer, packet delivery, and transport-level reliability over UDP.

- Explored how reliable data transfer can be implemented on top of UDP.
- Worked with packet sequencing, delivery checks, retransmission behavior, and file integrity.
- Improved my understanding of transport protocols, network behavior, and debugging distributed communication.
- Added a systems and networking perspective to my backend-development experience.
